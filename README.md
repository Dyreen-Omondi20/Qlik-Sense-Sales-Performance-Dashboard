Qlik Sense Sales Performance Dashboard
Description

A Qlik Sense application for analyzing sales performance using interactive dashboards powered by Qlik’s associative data model.

Tools

Qlik Sense Desktop

Data

Sales transaction dataset

Fields include date, product, region, revenue, and quantity

Data is simulated/anonymized for portfolio use

Features

KPI objects for sales and revenue

Dimension-based analysis (product, region)

Time-series visualizations

Interactive filtering via selections

Usage

Open the .qvf file in Qlik Sense Desktop to explore the dashboard.
